# 🔍 Smart Search Engine with AI Chatbot

An AI-powered academic research platform that combines intelligent search, query refinement, article analysis, and a context-aware chatbot into a single research workflow.

Instead of simply returning search results, the application improves the user's query, retrieves relevant research papers, explains why each paper matches the search, and enables AI-powered conversations before or after searching.

---

## ✨ Features

- 🤖 AI-powered query correction and refinement
- 📚 Search research papers from Google Scholar and other academic sources
- 🎯 AI relevance scoring for every search result
- 📝 AI-generated summary explaining why each paper matches the query
- 💬 Integrated AI chatbot for research discussions
- 🔄 Continue chatting about searched papers with full context
- ⚡ Search first, then chat, or chat first and search later
- 📊 Adjustable number of search results
- 🎨 Clean and responsive user interface

---

## 🧠 How It Works

1. User enters a research topic or question.
2. AI automatically corrects spelling and improves the search query.
3. The system searches academic databases.
4. Results are ranked according to AI relevance.
5. Each paper includes an AI-generated explanation.
6. Users can immediately discuss the results with the integrated AI chatbot.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/Smart-Search-Engine-with-AI-chatbot-attached.git
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file.

```env
OPENAI_API_KEY=your_openai_api_key
```

### Run the application

```bash
npm start
```

Open:

```
http://localhost:3000
```
